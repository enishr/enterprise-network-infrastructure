# Enterprise Network Infrastructure Design, Implementation and Security

## Project overview

A completed hands-on enterprise network simulation developed in Cisco Packet Tracer to practice network architecture, departmental segmentation, connectivity, security and troubleshooting.

## Objectives

- Design a segmented multi-department office network.
- Configure IP addressing, switching, 802.1Q trunks and inter-VLAN routing.
- Implement network services and controlled access between departments.
- Validate connectivity and document the implementation.

## Technologies

| Area | Technologies |
| --- | --- |
| Simulation | Cisco Packet Tracer, Cisco IOS |
| Switching | VLANs, access ports, 802.1Q trunking |
| Routing | IPv4 subnetting, router-on-a-stick |
| Services | DHCP, DNS, HTTP, NAT/PAT |
| Security | Extended ACLs, guest network isolation |
| Validation | Ping, Cisco IOS show commands, service and access tests |

## Network design

The simulated office includes IT, HR, Finance, Sales, Marketing, Administration and guest wireless networks. Departmental VLANs separate broadcast domains, while inter-VLAN routing and access control policies govern communication.

## Implementation and validation

The project covers VLAN creation, trunk configuration, router subinterfaces, IP addressing, network services, simulated ISP connectivity and ACL-based security. Connectivity and service testing form part of the project documentation.

## Project artifacts

The detailed technical report, topology screenshots and supporting evidence are to be added to this repository.

## Scope and limitations

This is a personal learning and portfolio project, not a production deployment. Simulation results do not establish production performance or security guarantees.
